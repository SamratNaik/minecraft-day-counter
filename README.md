# Day Counter

Day Counter is a lightweight Fabric client-side mod that displays the current
Minecraft day directly on the HUD.

The mod automatically detects the current game mode (Hardcore, Survival, or
Creative) and shows it as a label, or allows the label to be disabled entirely
for a minimal interface.

## Features
- Displays the current Minecraft day on the HUD
- Automatic game mode detection (Hardcore / Survival / Creative)
- Label modes: Auto, Custom text, or Off
- Compact, configurable background
- Adjustable HUD scale
- In-game settings screen
- Client-side only

## Compatibility
- Fabric Loader
- Minecraft 1.21
- Works with shaders (Iris, Sodium, etc.)
- Compatible with resource packs and custom fonts

## Installation
1. Install Fabric Loader for Minecraft 1.20.1
2. Install Fabric API
3. Place the mod JAR into the `mods` folder
4. Launch the game
